# Medicare Claims & 30-Day Readmission Analysis

## Overview

SQL-based analysis of synthetic Medicare claims data to examine inpatient utilization, chronic-condition burden, healthcare spending, and 30-day readmission patterns.

## Business Question

What patterns in Medicare inpatient utilization and chronic-condition burden are associated with hospital readmissions and healthcare spending?

## Data

- Source: CMS DE-SynPUD
- Data: 2008 Beneficiary Summary and Inpatient Claims
- Population: Synthetic Medicare beneficiaries
- Data is synthetic and should not be used to draw conclusions about real Medicare beneficiaries.

## Tools

- MySQL
- SQL
- GitHub

## Analysis

- Inpatient utilization
- Chronic-condition burden
- Length of stay
- Medicare payments
- 30-Day readmissions
- Cosst concentration
